# SYNAPSE // Deep Black Interactive Matrix (#000000)

Современный одностраничный сайт в премиальной эстетике глубокого черного цвета (`#000000`) с полноэкранным интерактивным Canvas-фоном, физикой рассеивания частиц, неоновым шлейфом курсора и реактивными стеклянными карточками (Glassmorphism).

---

## ⚡ Особенности и функционал

1. **Полноэкранный реактивный Canvas**:
   - Частицы физически выталкиваются курсором по закону обратных квадратов.
   - При остановке курсора или отведении мыши частицы плавно возвращаются в свои квази-стабильные орбиты с помощью гармонического затухания (harmonic spring damping).
   - Тонкие неоновые связующие линии (Constellation mesh) динамически соединяют соседние узлы и образуют связи с курсором.
   - Интерактивные кольцевые ударные волны (Shockwaves) при клике мыши или нажатии на CTA-кнопки.

2. **Неоновый шлейф курсора (Cursor Glow & Trail)**:
   - Мягкий радиальный градиент под курсором с радиусом рассеивания 180–320px.
   - Неоновый след (comet trail) с сужением и субпиксельным сглаживанием, повторяющий траекторию мыши и пальца на тач-экранах.
   - Поддержка 4 цветовых пресетов:
     - **Циан** (`#00f0ff`)
     - **Фиолет** (`#c084fc` / `#f43f5e`)
     - **Лунный** (`#ffffff` / `#94a3b8`)
     - **Матрица** (`#10b981` / `#00f0ff`)

3. **Hero-экран и Glassmorphism**:
   - Футуристичная типографика со светящимися градиентами.
   - CTA-кнопка с анимированным вращающимся неоновым бордером (`conic-gradient`) и импульсным откликом.
   - 3 карточки с эффектом матового стекла (`backdrop-filter: blur(28px)`), радиальным спотлайтом за курсором и интерактивным 3D-наклоном (perspective tilt).
   - Панель телеметрии в реальном времени (FPS, число узлов, координаты курсора).

4. **Производительность и адаптивность**:
   - Стабильные **60 FPS** на базе чистого `requestAnimationFrame`.
   - Автоматическая адаптация под плотность пикселей (`devicePixelRatio`) и разрешение экрана.
   - Полная поддержка тач-событий мобильных устройств (`touchstart`, `touchmove`, `touchend`).

## 🚀 Как запустить

### Вариант 1: Мгновенно в любом браузере (без сборки)
Просто дважды кликните по файлу `standalone.html` (или `index.html`) в проводнике Windows — проект откроется в Chrome, Edge, Firefox или Safari без необходимости устанавливать Node.js.

### Вариант 2: Локальный веб-сервер
Если у вас установлен Node.js или Python:
```bash
# Через npx (Node.js)
npx serve .

# Или через Python
python -m http.server 8000
```
Затем перейдите по адресу `http://localhost:8000` (или `http://localhost:3000`).

### Вариант 3: Использование в React + Tailwind проекте (Vite / Next.js)
Скопируйте файл `DeepBlackHero.jsx` в ваш проект React:
```jsx
import DeepBlackHero from './DeepBlackHero';

export default function App() {
  return <DeepBlackHero />;
}
```
Убедитесь, что в проекте подключен Tailwind CSS.
