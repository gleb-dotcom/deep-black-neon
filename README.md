# SYNAPSE // Deep Black Star Matrix (#000000)

Современный одностраничный сайт в премиальной эстетике глубокого черного цвета (`#000000`) с интерактивным Canvas-микрокосмосом звезд, физикой гравитационного роя за **Главной звездочкой (курсором)**, взрывами Суперновых, падающими метеорами и реактивным glassmorphism-интерфейсом.

---

## 🌟 Особенности и эффекты

1. **Главная звездочка (Alpha Star Cursor)**:
   - Курсор превращен в сияющую **4-лучевую звезду** с дифракционными лучами, вращающимся алмазным ядром и мягкой переливающейся короной.
   - При движении Главная звезда сбрасывает мерцающий шлейф космической пыли (Stardust Embers).

2. **Два режима физики звёзд (переключение кнопкой или `Пробел` / `M`)**:
   - **✨ Режим «Рой звёзд» (Swarm)**: 300+ звёзд притягиваются к Главной звезде и грациозно кружат вокруг неё по многослойным орбитам с орбитальной скоростью. При движении мыши звёзды летят следом, образуя хвост кометы.
   - **⚡ Режим «Дисперсия» (Repel)**: Звёзды физически выталкиваются от курсора по закону обратных квадратов и плавно возвращаются в исходное состояние при остановке.

3. **Множество типов звёзд и спецэффектов**:
   - **300+ звёзд**: фоновые микро-звёзды с синусоидальным мерцанием, средние неоновые звёзды и яркие 4-лучевые мерцающие звёзды.
   - **Взрывы Суперновы (Supernova Bursts)**: при каждом клике или таче рождается вспышка из 35 разлетающихся светящихся искр.
   - **Падающие метеоры (Shooting Stars)**: периодически проносящиеся сквозь космическое пространство падающие звёзды с градиентным хвостом.
   - **Неоновая паутина созвездий (Constellation mesh)**: соединяет соседние звёзды и Главную звезду тонкими светящимися линиями.

4. **4 цветовые палитры**:
   - **Циан** (`#00f0ff`)
   - **Фиолет** (`#c084fc` / `#f43f5e`)
   - **Лунный** (`#ffffff` / `#94a3b8`)
   - **Матрица** (`#10b981` / `#00f0ff`)

5. **Glassmorphism Hero-интерфейс**:
   - CTA-кнопка с анимированным вращающимся `conic-gradient` неоновым бордером.
   - 3 стеклянные карточки (`backdrop-blur-28px`) с динамическим спотлайтом и 3D-наклоном (perspective tilt).
   - Живая панель телеметрии: FPS, число звёзд, активный режим и координаты.
